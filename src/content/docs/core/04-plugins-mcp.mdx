## 이 문서는 뭔가요

Claude Code에는 기본 기능 말고도 더해서 쓸 수 있는 **확장 기능**이 있습니다. 크게 세 종류예요.

| 종류 | 한 줄 설명 |
|---|---|
| **플러그인** | 여러 도구를 세트로 묶어놓은 것 |
| **스킬** | 특정 작업 하나를 더 잘하게 해주는 능력 |
| **MCP 서버** | Claude를 노션, 슬랙 같은 다른 앱과 연결해주는 다리 |

전문 도구도 많이 섞여 있어서(법률, 금융, 마케팅 자동화 등) 전부 다 필요하지는 않습니다. 아래는 이 커뮤니티에서 만드는 종류의 사이트(1인 프로젝트, Astro/Next.js + Supabase + Vercel)에 실제로 도움이 될 만한 것만 골랐어요.

> **먼저:** 이 커리큘럼을 무사히 마치는 게 우선입니다. 아래 것들은 **5회차 다듬기부터** 하나씩 시도해보시면 좋아요.

:::caution[GitHub에서 남이 만든 템플릿을 통째로 가져오는 건 시즌이 끝나고]
"디자인 잘 된 오픈소스 템플릿을 받아서 쓰면 되지 않나" 싶으실 수 있어요. 그런데 6회차 안에서는 대체로 손해입니다.

- 템플릿은 **자기 페이지 구조**를 이미 갖고 있습니다. 2회차에 정한 내 목록과 안 맞아요
- 그걸 내 구조에 맞추려면 **코드를 읽을 줄 알아야** 합니다
- 4회차에 기능을 붙일 때 템플릿 구조 때문에 더 막힙니다
- 무엇보다 **"내가 만들었다"는 감각**이 사라집니다. 이 커뮤니티가 노리는 게 그건데요

대신 아래 **frontend-design 스킬**과 **DESIGN.md** 를 쓰세요. 남의 코드를 가져오는 게 아니라 "이런 느낌으로 만들어줘" 하고 참고만 시키는 방식이라, 내 구조를 그대로 두고 겉모습만 올려줍니다.

통짜 템플릿은 시즌이 끝나고 두 번째 사이트를 만드실 때 시도해보시면 좋아요.
:::

## 설치는 어떻게 하나요 (개요)

| 종류 | 설치 방법 |
|---|---|
| 스킬 · 플러그인 | Claude Code 안에서 `/plugin` 명령으로 찾아 설치합니다 |
| MCP 서버 | `claude mcp add` 계열 명령으로 내 계정·앱과 연결합니다 |

> **정확한 명령어는 버전마다 바뀔 수 있습니다.** 아래 예시는 방향을 보여드리는 것이고, 실제로 칠 때는 Claude Code에서 `/help`를 쳐서 **지금 내 버전에 있는 명령어**를 확인하세요. (확인 필요)

설치가 끝났다고 자동으로 다 되는 건 아닙니다. 스킬·플러그인은 설치해두면 필요할 때 Claude가 알아서 써요. 그래도 안 쓰는 것 같으면 아래처럼 원하는 걸 직접 말로 시키시면 됩니다.

## ❓ ChatGPT(Codex) 사용자도 이 스킬/플러그인을 쓸 수 있나요?

Claude Code와 ChatGPT/Codex는 도구 생태계가 살짝 다릅니다.

| 기능 | Claude Code | ChatGPT (Codex) |
|---|---|---|
| **컨텍스트 파일** | `CLAUDE.md` | `AGENTS.md` (똑같이 자동 인식!) |
| **프롬프트 템플릿** | 100% 동작 | 100% 동작 |
| **MCP 서버 (Notion 등)** | `claude mcp add` | MCP 사양을 지원하는 Codex/IDE 설정 사용 |
| **`/plugin` 전용 스킬** | 지원 | 프롬프트(지침)로 동일한 효과를 냄 |

> **결론:** ChatGPT(Codex)를 쓰더라도 `AGENTS.md` 파일과 AI 팀 프롬프트, DESIGN.md 파일은 그대로 잘 작동합니다. `/plugin` 형태의 스킬은 위 템플릿 프롬프트를 복사해서 지시하면 비슷한 결과를 얻으실 수 있어요.

## 결과물 디자인을 더 다듬고 싶다면: DESIGN.md

`frontend-design` 스킬 말고, 완성된 브랜드의 **디자인 규칙을 참고하는 방법**도 있습니다.

유명 브랜드(Claude, Stripe, Notion, Apple 등)의 색·글씨·간격 규칙을 마크다운 한 장으로 정리해둔 게 있어요. 그걸 `DESIGN.md` 라는 이름으로 프로젝트에 넣어두고 "이 규칙대로 해줘" 라고 시키면, AI가 그 기준을 지켜서 만들어줍니다.

**남의 코드를 가져오는 게 아니라 규칙만 참고하는 방식**이라, 내 페이지 구조와 기능은 그대로 남습니다.

## 자주 나오는 질문

**Q. 이거 몰라도 사이트 완성할 수 있나요?**
네. 6회차 커리큘럼은 **준비 → 도구 6종**만으로 끝까지 갑니다. 이 문서는 다 만들고 난 다음의 선택지예요.

**Q. 설치는 어떻게 하나요?**
스킬·플러그인은 Claude Code 안에서 `/plugin`, MCP는 `claude mcp add` 계열 명령으로 합니다. 정확한 구문은 `/help`로 확인해보세요. 위 "설치는 어떻게 하나요" 절도 함께 보시면 좋습니다.

**Q. 설치했는데 안 돼요.**
버전이나 명령어가 바뀌었을 수 있습니다. 각 도구의 공식 저장소·안내 문서를 다시 확인해보세요.

**Q. 전문 도구(법률, 금융, 마케팅 자동화 등)는 왜 안 다루나요?**
이 커뮤니티의 목표(1인 웹사이트 제작)와 결이 달라서 뺐습니다. 필요하신 분은 각자 검색해서 찾아보셔도 좋아요.
