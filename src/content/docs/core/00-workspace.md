title: 작업 공간 만들기
---

> **읽는 시점:** 1회차 직후 · 한 번 만들어두고 6주 내내 씁니다
> **읽는 시간:** 10분 · 따라 하는 시간 15분

---

## 이 문서는 뭔가요

1회차에 AI에게 "프로젝트 폴더를 만들어줘"라고 시켰습니다. 폴더는 잘 만들어졌어요.

그런데 그게 어디 있는지 모르겠다는 분이 많았습니다.

그럴 만합니다. 폴더가 어디에 만들어질지 아무도 안 정해줬으니까요. AI는 그냥 터미널이 켜져 있던 자리에 만들었고, 그 자리가 어디인지를 우리가 몰랐던 거예요.

그래서 **1회차에 만든 폴더는 버리고, 오늘 처음부터 다시 시작합니다.**

아까워하지 않으셔도 됩니다. 그 안에는 아직 내 것이 하나도 없어요. AI가 만들어준 기본 파일뿐이고, 그건 나중에 언제든 다시 만들 수 있습니다. 지금 자리를 제대로 잡아두는 편이 훨씬 이득이에요.

오늘은 앞으로 6주 동안 모든 작업이 일어날 딱 한 곳을 만듭니다. 그러고 나면 "내 폴더 어디 갔지" 하실 일이 없어요.

:::note[이 문서를 다 따라 하면]
`D:\workspace\my-site` 처럼 **내 프로젝트가 어디 있는지 주소로 말할 수 있게** 됩니다.
그리고 그 폴더를 VSCode로 열어두면, 앞으로 AI와 사이트를 만드는 모든 작업이 거기서 일어납니다.
:::

---

## 1단계 · 내 드라이브 확인하기

먼저 내 노트북에 저장 공간이 몇 개인지 봅니다.

1. 키보드에서 **윈도우 키 + E** 를 누릅니다 (파일 탐색기가 열립니다)
2. 왼쪽 목록에서 **내 PC** 를 클릭합니다
3. 가운데에 드라이브 목록이 보입니다

이렇게 생겼습니다.

| 보이는 것 | 무슨 뜻 |
|---|---|
| 로컬 디스크 (C:) 하나만 | C 드라이브만 있는 노트북 |
| 로컬 디스크 (C:) + 로컬 디스크 (D:) | 두 개 있는 노트북 |

**어느 쪽을 쓰나요?**

- **D가 있으면 D를 쓰세요.** C는 윈도우가 쓰는 공간이라 여유가 적습니다
- **C만 있으면 C를 쓰시면 됩니다.** 아무 문제 없어요

> 옆 사람과 달라도 괜찮습니다. 내가 어느 쪽인지만 기억하시면 돼요.

## 2단계 · workspace 폴더 만들기

이제 "코딩하는 방"을 하나 만듭니다.

1. 위에서 정한 드라이브를 **더블클릭**해서 들어갑니다
2. 빈 공간에서 **마우스 오른쪽 버튼** 클릭
3. **새로 만들기 → 폴더**
4. 이름을 **`workspace`** 라고 칩니다 (영문 소문자, 띄어쓰기 없이)
5. 엔터

**확인:** 그 폴더를 더블클릭해서 들어갔을 때, 위쪽 주소창에 이렇게 보이면 성공입니다.

```
D:\workspace
```

(C를 쓰는 분은 `C:\workspace`)

:::caution[이 규칙만 지키면 됩니다]
**앞으로 만드는 모든 프로젝트 폴더는 이 `workspace` 안에만 만듭니다.**
바탕화면, 문서, 다운로드 폴더에는 절대 만들지 마세요.
:::

**왜 바탕화면이나 문서 폴더는 안 되나요?**

| 이유 | 무슨 일이 생기나 |
|---|---|
| 원드라이브(OneDrive) 자동 동기화 | 파일이 클라우드로 오르내리면서 꼬입니다 |
| 경로에 한글이 들어감 | 도구가 주소를 못 읽고 에러가 납니다 |
| 매번 위치가 달라짐 | 지금 어디서 작업 중인지 알 수 없습니다 |

## 3단계 · 1회차에 만든 폴더 정리하기

1회차에 만든 폴더는 버립니다. 오늘부터 새 자리에서 시작할 거예요.

### 어디 있는지 찾기

Claude Code를 켜고 이렇게 물어보세요. 이게 제일 빠릅니다.

```
내가 지금 어느 폴더에 있는지 알려줘.
그리고 이 폴더의 전체 주소를 알려줘.
```

AI가 `C:\Users\내이름\my-site` 같은 주소를 알려줍니다. 그 주소를 파일 탐색기 주소창에 그대로 붙여넣으면 그 폴더가 열려요.

### 지우기

1. 찾은 폴더를 **한 번 클릭**해서 선택
2. 키보드 **Delete** 키

끝입니다. 휴지통으로 들어가니까 나중에 마음이 바뀌면 되돌릴 수도 있어요.

:::note[못 찾겠으면 그냥 두세요]
찾는 데 3분 넘게 걸리면 **그냥 놔두고 넘어가셔도 됩니다.** 안 지워도 아무 문제 없어요.
용량만 조금 차지할 뿐이고, 우리는 오늘부터 새 폴더에서만 작업할 거니까요.
:::

---

## 4단계 · 내 프로젝트 폴더 새로 만들기

이제 진짜 내 사이트가 살 집을 만듭니다.

1. `D:\workspace` 폴더 안으로 들어갑니다
2. 빈 공간에서 **마우스 오른쪽 버튼** 클릭
3. **새로 만들기 → 폴더**
4. 이름을 정합니다

**폴더 이름 규칙**

| | 예시 |
|---|---|
| ✅ 좋음 | `my-site`, `cafe-review`, `my-portfolio` |
| ❌ 안 됨 | `내 사이트` (한글), `my site` (띄어쓰기), `사이트!!` (특수문자) |

**영문 소문자 + 하이픈(-)** 만 쓰시면 안전합니다.

> 이름이 안 떠오르면 그냥 `my-site` 로 하세요. 나중에 바꿔도 됩니다.

**확인:** 주소창이 `D:\workspace\my-site` 로 보이면 성공입니다.

:::caution[폴더가 텅 비어 있는 게 정상입니다]
안에 아무것도 없습니다. 맞습니다.

이 폴더는 지금부터 채워나갈 **빈 작업실**이에요. 오늘은 아이디어를 정리하고,
실제 사이트 파일은 3회차에 AI가 여기다 만들어줍니다.
:::

## 5단계 · VSCode로 프로젝트 폴더 열기

여기가 제일 중요합니다. **VSCode에서 어느 폴더를 여느냐가 곧 "AI가 건드릴 수 있는 범위"입니다.**

1. VSCode를 켭니다
2. 왼쪽 위 **파일(File) → 폴더 열기(Open Folder)**
3. `D:\workspace\my-site` 를 찾아서 선택 → **폴더 선택**
4. "이 폴더의 작성자를 신뢰하십니까?" 라고 물으면 → **예, 신뢰합니다**

**확인:** VSCode 왼쪽 위에 폴더 이름(`MY-SITE`)이 보이면 성공입니다.

:::caution[`workspace`를 열면 안 됩니다]
`D:\workspace` 를 열지 말고, 그 **안에 있는 프로젝트 폴더**(`D:\workspace\my-site`)를 여세요.

`workspace`를 열면 AI가 앞으로 만들 다른 프로젝트까지 다 보게 됩니다.
그러면 엉뚱한 파일을 고치는 사고가 납니다.
:::

## 6단계 · Claude Code 확장 설치하고 열기

검은 터미널 창은 이제 안 씁니다. VSCode 안에 **채팅창처럼 생긴 패널**을 띄워서 쓸 거예요. 훨씬 편합니다.

### 설치

1. VSCode에서 **Ctrl + Shift + X** (확장 목록이 열립니다)
2. 검색창에 **`Claude Code`** 입력
3. 만든 곳이 **Anthropic** 인 것을 찾아 **Install** 클릭

### 열기

설치가 끝나면 **✱ 모양 아이콘**(스파크 아이콘)이 생깁니다. 이걸 누르면 Claude가 열려요.

아이콘은 세 군데에 있습니다.

| 어디 | 언제 보이나 |
|---|---|
| 편집기 **오른쪽 위** | **파일을 열어놨을 때만** 보입니다 |
| **왼쪽 세로 막대**(활동 표시줄) | 항상 보입니다 |
| 창 **오른쪽 아래**(상태 표시줄)의 `✱ Claude Code` | 항상 보입니다 |

:::caution[오늘은 오른쪽 위 아이콘이 안 보일 수 있습니다]
우리 폴더는 지금 비어 있어서 열어놓은 파일이 없습니다.
그러면 오른쪽 위 ✱ 아이콘이 **안 나타납니다. 고장이 아닙니다.**

**왼쪽 세로 막대의 ✱ 아이콘**이나 **오른쪽 아래 `✱ Claude Code`** 를 누르세요.
:::

### 로그인

처음 열면 로그인 화면이 뜹니다. **Sign in** 을 누르고 브라우저에서 승인하시면 돼요.
Claude Pro / Max 계정으로 로그인하면 추가 결제가 없습니다.

**확인:** 오른쪽(또는 새 탭)에 채팅 입력창이 보이면 성공입니다.

## 7단계 · 모델을 Opus로 설정하기

입력창에 `/` 를 치면 메뉴가 열립니다. 거기서 모델 바꾸기를 고르고 **Opus** 를 선택하세요.

```
/model
```

라고 쳐도 됩니다.

**왜 Opus 인가요?**

우리는 코드를 직접 안 씁니다. 말로 설명하면 AI가 알아서 만들어주길 기대하죠. 그러려면 AI가 내 말의 의도를 정확히 알아들어야 합니다.

Opus가 그걸 제일 잘해요. 더 가벼운 모델은 빠르지만 "내가 원한 게 이게 아닌데"가 자주 나오고, 그러면 다시 설명하느라 시간이 더 듭니다.

| 모델 | 특징 | 우리에게 |
|---|---|---|
| **Opus** | 제일 똑똑함. 의도를 잘 알아들음 | ✅ **이걸 씁니다** |
| Sonnet | 빠르고 균형이 좋음 | 한도가 걱정될 때 |
| Haiku | 제일 빠르고 가벼움 | 우리 작업엔 조금 아쉬움 |
| `default` | 계정에 맞는 걸 자동 선택 | 잘 모르겠을 때 |

:::note[사용량이 걱정되면 바꿔도 됩니다]
Opus는 똑똑한 만큼 사용량이 빨리 닳습니다. 한도가 차면 남은 시간을 못 써요.

지금 얼마나 썼는지 확인:
```
/usage
```

70%를 넘겼다면 Sonnet으로 내리시면 됩니다. 방법은 똑같아요.
```
/model
```
목록에서 **Sonnet** 선택. 언제든 다시 Opus로 올릴 수 있습니다.
:::

## 8단계 · Auto 모드로 두기

입력창 아래쪽을 보면 지금 모드가 적혀 있습니다. 그걸 눌러서 **Auto** 를 고르세요.

**모드가 뭔가요?**

AI가 파일을 고치려 할 때 "고쳐도 돼요?" 하고 물어볼지 말지를 정하는 설정입니다.

| 모드 | 어떻게 되나 |
|---|---|
| Manual | 할 때마다 하나하나 다 물어봅니다 |
| **Auto** | 안 물어보고 진행합니다. 대신 위험한 건 자동으로 막습니다 |

**왜 Auto 인가요?**

Manual로 두면 10분에 스무 번씩 "허용할까요?" 가 뜹니다. 그런데 우리는 코드를 모르니까 물어봐도 판단하기가 어려워요. 결국 계속 "예"만 누르게 되고, 그럴 거면 물어보는 의미가 없이 흐름만 끊깁니다.

Auto 모드는 그 대신 다른 AI가 뒤에서 안전 검사를 합니다. 파일을 지우거나, 비밀번호를 밖으로 보내거나, 되돌릴 수 없는 일을 하려 하면 자동으로 막고 그때만 물어봐요.

:::caution[대신 이건 알고 계세요]
**Auto가 100% 안전을 보장하지는 않습니다.** 안 물어보고 진행하니까, AI가 뭘 했는지는 나중에 확인해야 합니다.

그래서 회차마다 이렇게 물어보는 습관을 들이세요.

```
방금 뭘 만들었는지 한 줄씩만 설명해줘.
```

1회차의 "`y` 누르기 전에 한 번 멈추기" 규칙이 여기서는 "끝나고 뭘 했는지 물어보기" 로 바뀝니다.
:::

> 화면에 보이는 단어가 이 표와 조금 다를 수 있습니다. 도구가 계속 업데이트되기 때문이에요.
> 실제로 보이는 목록이 정답입니다. 헷갈리면 손 드세요.

## 여기까지 오면 준비 끝입니다

지금 화면은 이렇게 되어 있습니다.

```
VSCode 창 하나
  왼쪽    → 내 프로젝트 폴더 (아직 텅 비어 있음)
  오른쪽  → Claude 채팅창 (모델 Opus · 모드 Auto)
```

앞으로 6주 동안 이 화면에서 다 합니다.

폴더를 옮길 일도, 검은 터미널 창을 켤 일도, "내 파일 어디 갔지" 할 일도 없어요.
내가 만들고 싶은 걸 **오른쪽 채팅창에 말로 적으면, AI가 왼쪽 폴더 안에 만들어줍니다.**

| 회차 | 이 폴더 안에서 무슨 일이 |
|---|---|
| **오늘 (2회차)** | 아직 파일은 안 생깁니다. 어떤 페이지가 필요한지 정합니다 |
| 3회차 | AI가 실제 사이트 파일을 만들어줍니다. 화면이 뜹니다 |
| 4회차 | 기능이 하나 붙습니다 |
| 5회차 | 보기 좋게 다듬습니다 |
| 6회차 | 세상에 공개합니다 |

오늘 폴더가 비어 있는 게 정상입니다. 오늘은 "뭘 만들지"를 정하는 날이에요.

## 다 됐는지 확인하기

이 6개가 다 되면 끝입니다.

- [ ] 파일 탐색기에서 `D:\workspace` (또는 `C:\workspace`) 가 보인다
- [ ] 그 안에 내 프로젝트 폴더가 있다 (안은 비어 있어도 됩니다)
- [ ] VSCode 왼쪽 위에 내 프로젝트 폴더 이름이 보인다
- [ ] Claude 채팅창이 열리고 로그인이 되어 있다
- [ ] 모델이 **Opus** 로 되어 있다
- [ ] 모드가 **Auto** 로 되어 있다

## 자주 막히는 곳

| 증상 | 해결 |
|---|---|
| 파일 탐색기에 D 드라이브가 없음 | 정상입니다. C를 쓰시면 됩니다 |
| 폴더를 못 찾겠음 | Claude에 "지금 어느 폴더에 있는지 알려줘" 라고 물어보세요 |
| VSCode에서 폴더 열기가 어디 있는지 모르겠음 | 왼쪽 위 **파일** 메뉴 안에 있습니다 |
| 오른쪽 위에 ✱ 아이콘이 없음 | 정상입니다. 열어놓은 파일이 없어서 그래요. 왼쪽 세로 막대나 오른쪽 아래 `✱ Claude Code` 를 누르세요 |
| 설치했는데 아이콘이 아예 안 보임 | VSCode를 껐다 켜세요 |
| 로그인 화면이 계속 뜸 | 브라우저에서 claude.ai 로그인이 되어 있는지 먼저 확인 |
| 모델·모드를 어디서 바꾸는지 모르겠음 | 모델은 입력창에 `/model`, 모드는 입력창 아래쪽 글자를 클릭 |
| 채팅창이 왼쪽 폴더와 다른 걸 보는 것 같음 | VSCode에서 폴더를 잘못 열었습니다. 5단계를 다시 해보세요 |

**3분 넘게 막히면 손 드세요.** 혼자 헤매지 않는 게 규칙입니다.

## 자주 나오는 질문

**Q. 프로젝트를 여러 개 만들어도 되나요?**
됩니다. `workspace` 안에 폴더를 하나 더 만들면 돼요. 단, VSCode에서는 한 번에 하나씩 여시는 게 좋습니다.

**Q. 폴더 이름을 나중에 바꿔도 되나요?**
됩니다. 다만 바꾸고 나면 VSCode에서 폴더를 다시 열어야 해요.

**Q. 파일 탐색기 주소창이 어디예요?**
창 위쪽에 `내 PC > 로컬 디스크 (D:)` 처럼 적힌 줄입니다. 그 줄을 클릭하면 `D:\workspace` 같은 글자로 바뀝니다.

**Q. 1회차에 만든 폴더를 꼭 지워야 하나요?**
아니요. 안 지워도 아무 문제 없습니다. 다만 그 폴더는 이제 안 쓰니까, 헷갈리지 않게 지우시길 권할 뿐이에요.

**Q. 폴더가 비어 있는데 이게 맞나요?**
맞습니다. 오늘은 뭘 만들지 정하는 날이라 파일이 안 생겨요. 3회차에 AI가 여기다 사이트 파일을 만들어줍니다.

**Q. 그럼 오늘 AI는 뭘 하나요?**
내 아이디어를 듣고 어떤 페이지가 필요한지 같이 정리해줍니다. 코드는 안 씁니다.

**Q. 1회차에 배운 검은 터미널 창은 이제 안 쓰나요?**
안 씁니다. 채팅창이 훨씬 편해요. 1회차에 설치해둔 건 그대로 두시면 됩니다.

**Q. Auto 모드면 AI가 마음대로 다 해버리는 거 아닌가요?**
파일을 만들고 고치는 건 안 물어보고 합니다. 하지만 파일을 지우거나 되돌릴 수 없는 일을 하려 하면 자동으로 막히고 그때는 물어봐요. 대신 **끝나고 "뭘 했는지" 한 번 물어보는 습관**을 들이세요.

**Q. Opus를 쓰면 한도가 빨리 찬다면서요?**
맞습니다. 그래서 `/usage` 로 가끔 확인해보세요. 70%를 넘었으면 `/model` 로 Sonnet으로 내리면 됩니다. 언제든 다시 올릴 수 있어요.
