title: 작업 공간 만들기
---

> **읽는 시점:** 1회차 직후 · 한 번 만들어두고 6주 내내 씁니다
> **읽는 시간:** 10분 · 따라 하는 시간 15분

---

## 이 문서는 뭔가요

1회차에 AI에게 "프로젝트 폴더를 만들어줘"라고 시켰습니다. 폴더는 잘 만들어졌어요.

**그런데 그게 어디 있는지 모르겠는 분이 많습니다.**

당연합니다. 폴더가 어디에 만들어질지 아무도 안 정해줬으니까요. AI는 그냥 **터미널이 켜져 있던 자리**에 만들었습니다. 그게 어디인지 우리가 몰랐던 거죠.

**그래서 1회차에 만든 폴더는 버리고, 오늘 처음부터 다시 시작합니다.**

아까워하지 마세요. 그 안에는 아직 **내 것이 하나도 없습니다.** AI가 만들어준 기본 파일뿐이고, 그건 나중에 언제든 다시 만들 수 있어요. 지금 자리를 제대로 잡는 게 훨씬 이득입니다.

오늘 **앞으로 6주 동안 모든 작업이 일어날 딱 한 곳**을 만듭니다. 그러고 나면 다시는 "내 폴더 어디 갔지"가 없습니다.

:::note[이 문서를 다 따라 하면]
`D:\workspace\my-site` 처럼 **내 프로젝트가 어디 있는지 주소로 말할 수 있게** 됩니다.
그리고 그 폴더를 VSCode로 열어두면, **앞으로 AI와 사이트를 만드는 모든 작업이 거기서** 일어납니다.
:::

## 1단계 · 내 드라이브 확인하기

먼저 내 노트북에 저장 공간이 몇 개인지 봅니다.

1. 키보드에서 **윈도우 키 + E** 를 누릅니다 (파일 탐색기가 열립니다)
2. 왼쪽 목록에서 **내 PC** 를 클릭합니다
3. 가운데에 드라이브 목록이 보입니다

**이렇게 생겼습니다.**

| 보이는 것 | 무슨 뜻 |
|---|---|
| 로컬 디스크 (C:) 하나만 | C 드라이브만 있는 노트북 |
| 로컬 디스크 (C:) + 로컬 디스크 (D:) | 두 개 있는 노트북 |

**어느 쪽을 쓰나요?**

- **D가 있으면 → D를 쓰세요.** C는 윈도우가 쓰는 공간이라 여유가 적습니다
- **C만 있으면 → C를 쓰세요.** 아무 문제 없습니다

> 옆 사람과 달라도 괜찮습니다. **내가 어느 쪽인지만 기억하면 됩니다.**

## 2단계 · workspace 폴더 만들기

이제 "코딩하는 방"을 하나 만듭니다.

1. 위에서 정한 드라이브를 **더블클릭**해서 들어갑니다
2. 빈 공간에서 **마우스 오른쪽 버튼** 클릭
3. **새로 만들기 → 폴더**
4. 이름을 **`workspace`** 라고 칩니다 (영문 소문자, 띄어쓰기 없이)
5. 엔터

**확인:** 그 폴더를 더블클릭해서 들어갔을 때, 위쪽 주소창에 이렇게 보이면 성공입니다.

```
D:\workspace
```

(C를 쓰는 분은 `C:\workspace`)

:::caution[이 규칙만 지키면 됩니다]
**앞으로 만드는 모든 프로젝트 폴더는 이 `workspace` 안에만 만듭니다.**
바탕화면, 문서, 다운로드 폴더에는 절대 만들지 마세요.
:::

**왜 바탕화면이나 문서 폴더는 안 되나요?**

| 이유 | 무슨 일이 생기나 |
|---|---|
| 원드라이브(OneDrive) 자동 동기화 | 파일이 클라우드로 오르내리면서 꼬입니다 |
| 경로에 한글이 들어감 | 도구가 주소를 못 읽고 에러가 납니다 |
| 매번 위치가 달라짐 | 지금 어디서 작업 중인지 알 수 없습니다 |

## 3단계 · 1회차에 만든 폴더 정리하기

1회차에 만든 폴더는 **버립니다.** 오늘부터 새 자리에서 시작할 거예요.

### 어디 있는지 찾기

Claude Code를 켜고 이렇게 물어보세요. **이게 제일 빠릅니다.**

```
내가 지금 어느 폴더에 있는지 알려줘.
그리고 이 폴더의 전체 주소를 알려줘.
```

AI가 `C:\Users\내이름\my-site` 같은 주소를 알려줍니다. 그 주소를 파일 탐색기 주소창에 그대로 붙여넣으면 그 폴더가 열립니다.

### 지우기

1. 찾은 폴더를 **한 번 클릭**해서 선택
2. 키보드 **Delete** 키

끝입니다. 휴지통으로 들어가니까 나중에 마음이 바뀌면 되돌릴 수도 있어요.

:::note[못 찾겠으면 그냥 두세요]
찾는 데 3분 넘게 걸리면 **그냥 놔두고 넘어가세요.** 안 지워도 아무 문제 없습니다.
용량만 조금 차지할 뿐이고, 우리는 오늘부터 새 폴더에서만 작업할 거예요.
:::

---

## 4단계 · 내 프로젝트 폴더 새로 만들기

이제 진짜 내 사이트가 살 집을 만듭니다.

1. `D:\workspace` 폴더 안으로 들어갑니다
2. 빈 공간에서 **마우스 오른쪽 버튼** 클릭
3. **새로 만들기 → 폴더**
4. 이름을 정합니다

**폴더 이름 규칙**

| | 예시 |
|---|---|
| ✅ 좋음 | `my-site`, `cafe-review`, `my-portfolio` |
| ❌ 안 됨 | `내 사이트` (한글), `my site` (띄어쓰기), `사이트!!` (특수문자) |

**영문 소문자 + 하이픈(-)** 만 씁니다. 이게 안전합니다.

> **이름이 안 떠오르면** 그냥 `my-site` 로 하세요. 나중에 바꿔도 됩니다.

**확인:** 주소창이 `D:\workspace\my-site` 로 보이면 성공입니다.

:::caution[폴더가 텅 비어 있는 게 정상입니다]
안에 아무것도 없습니다. 맞습니다.

**이 폴더는 지금부터 채워나갈 빈 작업실**이에요. 오늘은 아이디어를 정리하고,
실제 사이트 파일은 **3회차에 AI가 여기다 만들어줍니다.**
:::

---

## 5단계 · VSCode로 프로젝트 폴더 열기

여기가 제일 중요합니다. **VSCode에서 어느 폴더를 여느냐가 곧 "AI가 건드릴 수 있는 범위"입니다.**

1. VSCode를 켭니다
2. 왼쪽 위 **파일(File) → 폴더 열기(Open Folder)**
3. `D:\workspace\my-site` 를 찾아서 선택 → **폴더 선택**
4. "이 폴더의 작성자를 신뢰하십니까?" 라고 물으면 → **예, 신뢰합니다**

**확인:** VSCode 왼쪽 위에 폴더 이름(`MY-SITE`)이 보이면 성공입니다.

:::caution[`workspace`를 열면 안 됩니다]
`D:\workspace` 를 열지 말고, 그 **안에 있는 프로젝트 폴더**(`D:\workspace\my-site`)를 여세요.

`workspace`를 열면 AI가 앞으로 만들 다른 프로젝트까지 다 보게 됩니다.
그러면 엉뚱한 파일을 고치는 사고가 납니다.
:::

---

## 6단계 · VSCode 안에서 Claude Code 켜기

이제부터 **터미널을 따로 켜지 않습니다.** VSCode 안에서 다 합니다.

1. VSCode에서 **Ctrl + `** (백틱 키, 보통 숫자 1 왼쪽에 있습니다)
   - 잘 안 되면 위쪽 메뉴 **터미널(Terminal) → 새 터미널(New Terminal)**
2. 아래쪽에 검은 창이 열립니다
3. 그 창의 맨 앞에 **지금 폴더 주소**가 적혀 있습니다. 확인하세요

```
D:\workspace\my-site>
```

4. 여기에 `claude` 를 치고 엔터

```
claude
```

**이렇게 켜면 AI가 자동으로 이 폴더만 봅니다.** 1회차에 있었던 "명령어를 쳤는데 아무 반응 없음 → 지금 어느 폴더인지 확인" 문제가 아예 사라집니다.

## 7단계 · 모델 설정하기

Claude Code가 켜지면 딱 한 번 설정합니다.

```
/model
```

목록이 뜨면 **`default`** 를 고르고 엔터.

**왜 `default` 인가요?**

| 설정 | 뭐가 좋은가 | 뭐가 위험한가 |
|---|---|---|
| **`default`** | 내 계정에 맞는 걸 **알아서** 골라줍니다 | 없습니다. 이걸 쓰세요 |
| `opus` | 제일 똑똑합니다 | **사용량이 제일 빨리 닳습니다** |
| `sonnet` | 균형이 좋습니다 | 아주 어려운 작업에선 조금 약합니다 |
| `haiku` | 제일 빠릅니다 | 우리가 하는 작업에는 부족합니다 |

:::danger[제일 흔한 사고]
"제일 좋은 걸로 하자"며 `opus`로 바꿨다가 **회차 중간에 사용량 한도가 찹니다.**
그러면 남은 시간 동안 아무것도 못 하고 옆 사람 화면만 보게 됩니다.

`default` 로 두세요. 그게 2시간을 끝까지 쓰는 방법입니다.
:::

> 화면에 보이는 단어가 이 표와 조금 다를 수 있습니다. 도구가 계속 업데이트되기 때문이에요.
> **`/model` 을 쳤을 때 실제로 보이는 목록이 정답입니다.**

## 여기까지 오면 준비 끝입니다

지금 화면은 이렇게 되어 있습니다.

```
VSCode 창 하나
  왼쪽    → 내 프로젝트 폴더 (아직 텅 비어 있음)
  아래쪽  → Claude Code가 켜진 터미널
```

**앞으로 6주 동안 이 화면에서 다 합니다.**

폴더를 옮길 일도, 터미널을 따로 켤 일도, "내 파일 어디 갔지" 할 일도 없습니다.
내가 만들고 싶은 걸 **말로 설명하면 AI가 이 폴더 안에 만들어줍니다.**

| 회차 | 이 폴더 안에서 무슨 일이 |
|---|---|
| **오늘 (2회차)** | 아직 파일은 안 생깁니다. **어떤 페이지가 필요한지 정합니다** |
| 3회차 | AI가 실제 사이트 파일을 만들어줍니다. 화면이 뜹니다 |
| 4회차 | 기능이 하나 붙습니다 |
| 5회차 | 보기 좋게 다듬습니다 |
| 6회차 | 세상에 공개합니다 |

**오늘 폴더가 비어 있는 게 정상입니다.** 오늘은 "뭘 만들지"를 정하는 날이에요.

---

## 다 됐는지 확인하기

이 4개가 다 되면 끝입니다.

- [ ] 파일 탐색기에서 `D:\workspace` (또는 `C:\workspace`) 가 보인다
- [ ] 그 안에 내 프로젝트 폴더가 있다 (안은 비어 있어도 됩니다)
- [ ] VSCode 왼쪽 위에 내 프로젝트 폴더 이름이 보인다
- [ ] VSCode 터미널에서 `claude` 가 켜진다

## 자주 막히는 곳

| 증상 | 해결 |
|---|---|
| 파일 탐색기에 D 드라이브가 없음 | 정상입니다. C를 쓰세요 |
| 폴더를 못 찾겠음 | Claude Code에 "지금 어느 폴더에 있는지 알려줘" 라고 물어보세요 |
| VSCode에서 폴더 열기가 어디 있는지 모르겠음 | 왼쪽 위 **파일** 메뉴 안에 있습니다 |
| 터미널이 안 열림 | 위쪽 **터미널 → 새 터미널** |
| 터미널 주소가 내 프로젝트 폴더가 아님 | VSCode에서 폴더를 잘못 열었습니다. 5단계를 다시 하세요 |
| `claude` 를 쳤는데 없는 명령어라고 나옴 | VSCode를 껐다 켜세요 |

**3분 넘게 막히면 손 드세요.** 혼자 헤매지 않는 게 규칙입니다.

## 자주 나오는 질문

**Q. 프로젝트를 여러 개 만들어도 되나요?**
됩니다. `workspace` 안에 폴더를 하나 더 만들면 돼요. 단, VSCode에서는 **한 번에 하나씩** 여세요.

**Q. 폴더 이름을 나중에 바꿔도 되나요?**
됩니다. 다만 바꾸고 나면 VSCode에서 **폴더를 다시 열어야** 합니다.

**Q. 파일 탐색기 주소창이 어디예요?**
창 위쪽에 `내 PC > 로컬 디스크 (D:)` 처럼 적힌 줄입니다. 그 줄을 클릭하면 `D:\workspace` 같은 글자로 바뀝니다.

**Q. 1회차에 만든 폴더를 꼭 지워야 하나요?**
아니요. 안 지워도 아무 문제 없습니다. 다만 **그 폴더는 이제 안 씁니다.** 헷갈리지 않게 지우는 걸 권할 뿐이에요.

**Q. 폴더가 비어 있는데 이게 맞나요?**
맞습니다. 오늘은 **뭘 만들지 정하는 날**이라 파일이 안 생깁니다. 3회차에 AI가 여기다 사이트 파일을 만들어줍니다.

**Q. 그럼 오늘 AI는 뭘 하나요?**
내 아이디어를 듣고 **어떤 페이지가 필요한지 같이 정리해줍니다.** 코드는 안 씁니다.
