## 오늘 미리 알아두면 좋은 것

**오늘은 세팅하는 날입니다.** 아직 사이트 비슷한 것도 안 나와요.

그런데 이 세팅이 혼자 하면 대부분 접게 되는 지점이에요. 유튜브 보고 따라 하다가 검은 터미널 창에서 막혀서 그만두는 그 지점. 오늘은 6명이 같이 뚫습니다.

시간이 부족해도 괜찮아요. 못 끝낸 건 집에서 이어서 하고, 내일 또 만납니다.

## 오늘 함께 뚫는 것 4개

### 1. Node.js — 사이트를 돌리는 엔진

**설치:** nodejs.org → LTS 버전 다운로드 → 계속 "다음"

**확인:**
```
node -v
```
`v20.11.0` 같은 숫자가 나오면 성공.

**안 되면:** 터미널을 껐다 다시 켜보세요. 90%는 이걸로 해결됩니다.

---

### 2. VSCode — 코드를 들여다보는 창

**설치:** code.visualstudio.com → 다운로드 → 설치

**확인:** 프로그램이 열리고 왼쪽에 파일 목록 자리가 보이면 성공.

**알아둘 것:** 코드를 쓰라고 있는 게 아니라 보라고 있는 창입니다.

## 자주 막히는 곳

여기까지 오면서 막힌 게 있다면 대부분 이 표 안에 있습니다.

| 증상 | 해결 |
|---|---|
| `node -v` 가 안 먹힘 | 터미널 껐다 켜기 |
| `npm install` 하다가 권한 에러 | 관리자 권한 터미널로 다시 실행 |
| Claude Code 로그인이 안 됨 | 브라우저에서 claude.ai 로그인 먼저 확인 |
| 명령어를 쳤는데 아무 반응 없음 | 지금 어느 폴더에 있는지 확인. 프로젝트 폴더 안이어야 함 |

**3분 넘게 막히면 손 드세요.** 혼자 헤매지 않는 게 오늘의 규칙입니다.

## 오늘의 하이라이트 · 첫 명령 던지기

세팅이 끝나면 이제 AI에게 처음으로 시킵니다.

터미널에서 `claude` (또는 `codex`)를 실행하고, 이렇게 쳐보세요.

```
Next.js 프로젝트를 새로 만들어줘.
TypeScript로, 가장 기본 설정(defaults)으로 질문 없이 생성해줘.
폴더 이름은 my-site 로 해줘.
```

> **💡 팁:** "질문 없이 기본 설정으로"를 명시하면 AI가 여러 옵션(Tailwind, ESLint 등)을 묻는 질문 폭탄을 던지지 않고 알아서 깔끔하게 만들어줍니다.

AI가 명령어를 자동으로 쳐 내려가면서 파일이 좌르르 생깁니다.

**여기서 잠깐.** `y` 를 누르기 전에 화면을 한 번 보세요. 뭘 하려는 건지 대충이라도요.

## 오늘 손에 남는 것

**프로젝트 폴더 하나.** VSCode로 열어보면 파일이 여러 개 들어 있어요.

아직 눈에 보이는 건 없지만, 마지막에 세상에 나갈 사이트가 여기서 시작합니다.

:::note[이 폴더는 2회차에 다시 만듭니다]
오늘은 **AI에게 시켜보는 것**이 목적이에요. 폴더가 어디에 만들어질지 정하지 않고 시켰기 때문에, 나중에 "내 폴더 어디 갔지" 하기 쉽습니다.

그래서 2회차에 **자리를 제대로 정해서 새로 만듭니다.** 오늘 만든 건 그때 버려도 괜찮아요.

아까워하지 않으셔도 됩니다. 안에 아직 내 것이 하나도 없거든요.
:::
