## 오늘 새로 준비하는 것 · Supabase

**Supabase가 뭔가요?**
데이터를 저장하는 창고입니다.

지금 화면은 예쁘기만 하고 아무것도 기억하지 못합니다. 리뷰를 써도 새로고침하면 사라져요.
Supabase가 그걸 대신 보관해줍니다.

### 어디까지 하나

1. **가입 & 프로젝트 확인** — 지난 시간에 가입해둔 supabase.com에 로그인
2. **테이블 하나 만들기** — 화면에서 클릭으로. **SQL 안 씁니다**
3. **API 키 2개 복사해두기** ← 이거 중요

### API 키가 뭔가요

내 데이터 창고의 **주소와 열쇠**입니다.

| 이름 | 뭔가 |
|---|---|
| **Project URL** | 창고 주소 |
| **anon key** | 창고 문 여는 열쇠 |

이 두 개를 AI에게 주면 나머지는 AI가 코드에 넣어줍니다.

:::caution[이 키는 남에게 보여주지 마세요]
채팅창에 붙여넣는 건 괜찮습니다. 다만 GitHub에 올릴 때는 `.env` 파일에 숨겨야 해요.

AI에게 키를 줄 때 **"이 키를 .env 파일에 넣어줘"** 라고 함께 말하세요.
:::

### 우리가 안 하는 것

DB 설계, 정규화, SQL, 인덱스 — 안 합니다.
`이름`, `내용`, `날짜` 정도의 칸을 클릭으로 만들면 끝이에요.

## 오늘 하는 것 3단계

### 1단계 · 먼저 폼만 만들기 (30분) — 여기까진 6명 다 성공합니다

Supabase 없이 화면에서만 되는 걸 먼저 만듭니다.

**대괄호 안만 내 것으로 바꾸시면 됩니다.**

```
홈 화면에 [리뷰]를 입력하는 폼을 추가해줘.
입력 칸: [카페 이름], [별점], [한 줄 평]
저장 버튼을 누르면 아래 목록에 바로 나타나면 돼.

아직 데이터베이스는 연결하지 마. 화면에서만 되면 돼.
```

> 산책 코스 사이트라면 `[코스 이름], [난이도], [한 줄 소감]` 처럼요.
> 뭘 넣을지 모르겠으면 `내 사이트에 맞는 입력 칸을 3개만 정해줘` 라고 먼저 물어보세요.

**결과:** 입력하고 저장하면 목록에 뜹니다. 새로고침하면 사라져요. 괜찮습니다.

오늘의 최소 결과물이 이겁니다. 여기까지만 하셔도 오늘 온 보람이 있어요.

---

### 2단계 · Supabase 연결 시도 (30분) — 여기서부터 갈립니다

```
이제 Supabase에 연결해줘.

내 Supabase 정보야:
Project URL: [붙여넣기]
anon key: [붙여넣기]

테이블 이름은 [reviews] 이고, 칸은 [name, rating, comment] 야.

저장 버튼을 누르면 Supabase에 들어가고,
새로고침해도 목록이 그대로 남아 있게 해줘.

키는 .env 파일에 넣어서 코드에 직접 안 보이게 해줘.
```

> 테이블·칸 이름은 아까 Supabase 화면에서 직접 만드신 그 이름을 그대로 적으시면 됩니다.

**여기서 첫 에러를 만나게 됩니다.**

지금까지는 AI가 뽑아주면 됐어요. 오늘은 뽑아줘도 한 번에 안 될 수 있습니다.
이 순간이 오늘의 진짜 시작이에요.

---

### 에러가 나면 이 순서로

혼자 30분씩 헤매지 않으셔도 됩니다.

1. **AI에게 에러 메시지를 그대로 붙여넣기** (3분)
2. 안 풀리면 **카톡방에 스크린샷** (즉시)
3. **옆 사람에게 물어보기**

**에러 프롬프트**

```
Supabase를 연결했는데 에러가 나:

[에러 메시지 붙여넣기]

지금 화면에서는 [저장 버튼을 눌러도 아무 일도 안 일어나].
뭘 확인해야 해?
```

**같은 에러가 세 번째라면**

```
같은 에러가 세 번째야. 아까 알려준 방법대로 했는데 또 났어.
지금 상태를 처음부터 다시 확인해줘. 뭘 놓쳤을까?
```

### 3단계 · GitHub에 중간 저장 (10분)

오늘 어렵게 만든 것을 GitHub에 보관해 둡니다. 3회차에 한 번 해보셨으니 오늘은 금방이에요.

**어디까지 왔든 올리시면 됩니다.** 폼까지만 됐어도 그 상태로 올려두는 게 맞아요.

```
오늘 작업한 걸 GitHub에 올려줘.
.env 파일은 올라가지 않게 확인하고, 커밋 메시지는 "4회차 기능 추가" 로 해줘.
```

:::caution[.env 가 올라가지 않았는지 꼭 확인하세요]
`.env` 안에는 Supabase 열쇠가 들어 있습니다. GitHub에 올라가면 남이 내 데이터 창고를 열 수 있어요.

위 프롬프트에 이미 넣어뒀지만, 한 번 더 물어보셔도 좋습니다.

```
방금 올린 것 중에 .env 파일이 들어갔는지 확인해줘.
```
:::
