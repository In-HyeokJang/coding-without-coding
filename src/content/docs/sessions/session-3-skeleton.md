## 토큰 아끼는 법 4가지

오늘은 코드가 많이 나오는 날이라 사용량이 평소보다 빨리 닳아요.

**시작하기 전에** 이 4개를 먼저 읽어두시면, 오늘 하루가 훨씬 여유롭습니다.

**① 목록은 채팅창 말고 `CLAUDE.md` 에 넣어두기**
붙여넣을 때마다 사용량이 나가거든요. 파일에 있으면 `아까 그 목록대로` 한마디면 끝나요.

**② "왜 그렇게 만들었는지" 는 묻지 않기**
설명이 길수록 사용량이 큽니다. 프롬프트 끝에 `설명은 빼고 만들어줘` 를 붙여보세요.

**③ 마음에 안 들어도 처음부터 다시 시키지 않기**
다시 만들면 통째로 다시 나가거든요. `방금 바꾼 걸 되돌려줘` 가 훨씬 적게 들어요.

**④ 한 번에 다섯 개 시키지 않기**
엉뚱하게 나오면 그만큼 다시 해야 하니까요. 하나 시키고 → 확인 → 다음.

:::tip[중간에 한 번 확인해보세요]
채팅창에 `/usage` 를 치면 지금까지 얼마나 썼는지 나옵니다.

70%를 넘겼으면 `/model` 로 Sonnet으로 내리셔도 돼요. 오늘 남은 작업은 Sonnet으로도 충분합니다.

:::note[Next.js 가 뭐고, TypeScript 는 또 뭔가요]
**Next.js는 웹사이트를 만드는 도구 모음이에요.** 우리가 이걸 쓰는 이유는 두 가지입니다.

- 2회차에 만든 `CLAUDE.md` 에 이미 이걸로 적어뒀어요
- 6회차에 공개할 **Vercel** 과 같은 회사가 만든 도구라, 배포가 제일 쉽습니다

**TypeScript 는 뭔가요?**

웹사이트를 움직이는 언어는 원래 **자바스크립트(JavaScript)** 예요. TypeScript는 별개의 언어가 아니라, 그 자바스크립트에 **"이 칸에는 이런 것만 들어간다"** 를 미리 적어두게 하는 겁니다.

리뷰 하나를 예로 들면 이래요.

```
카페 이름 → 글자
별점      → 숫자
한 줄 평  → 글자
```

이렇게 적어두면, 별점 자리에 `"다섯개"` 같은 글자가 들어가는 순간 **그 자리에 바로 표시가 뜹니다.**

**우리한테 왜 좋은가요?** 나보다 <mark>AI를 더 많이 돕기 때문입니다.</mark>

AI는 홈 화면에서 `별점` 이라고 만들어놓고, 상세 페이지에서는 `평점` 이라고 부르는 실수를 종종 해요. 파일이 여러 개로 갈라질 때 특히 그렇습니다.

- **TypeScript** — 그 자리에 바로 표시가 떠서, AI가 스스로 알아채고 고칩니다
- 없으면 — 아무 말 없이 넘어가고, 화면에 별점 자리가 그냥 **빈칸**으로 나옵니다

빈칸이 제일 곤란해요. 에러 메시지가 없으니 AI에게 **붙여넣을 게 없거든요.**

> 그리고 하나 더 — 커뮤니티가 끝난 뒤에도 계속 만드실 거잖아요.
> 요즘 AI 코딩 도구는 전부 TypeScript로 코드를 뱉습니다. 여기서 익숙해져 두시는 게 이득이에요.

**Tailwind CSS 도 같이 깔립니다**

프로젝트를 만들면 `Tailwind CSS` 라는 것도 함께 들어와요. **색과 간격을 정하는 도구**입니다.

코드를 열어보면 `className="flex gap-4"` 같은 영어가 잔뜩 보일 텐데, 그게 Tailwind예요.
"글자 크게, 간격 넓게" 같은 걸 짧은 단어로 적어둔 겁니다.

<mark>배우지 않으셔도 됩니다.</mark> 5회차에 "글씨 좀 크게 해줘" 라고 말하면 AI가 저걸 고칩니다.
이름만 알아두시면, 코드를 봤을 때 "아 저게 디자인 부분이구나" 하고 넘어갈 수 있어요.
:::

## 2단계 · 화면 켜고 내 사이트와 만나기 (25분)

만들어진 파일을 브라우저에서 열어봅니다.

### ① 서버 켜기

내 노트북 안에 **작은 웹서버**를 띄웁니다. 이게 있어야 브라우저에서 볼 수 있어요.

```
지금 만든 걸 브라우저에서 볼 수 있게 실행해줘.
```

직접 치셔도 됩니다.

```
npm run dev
```

성공하면 글자가 몇 줄 뜨는데, **그 안에 이 주소가 보이면 된 거예요.**

```
- Local:  http://localhost:3000
```

위아래에 `Next.js`, `Ready in ...` 같은 글자가 같이 뜹니다. 그 줄들은 안 읽으셔도 돼요. **주소 한 줄만** 찾으시면 됩니다.

브라우저 주소창에 **`localhost:3000`** 을 치고 엔터를 누르시면 됩니다.

:::caution[이 주소는 나만 볼 수 있어요]
옆 사람 컴퓨터에서는 안 열립니다. 이 주소를 그대로 보내셔도 상대방은 못 열어요.

세상에 공개하는 건 **6회차**입니다. 오늘은 내 노트북 안에서만 살아 있어요.
:::

### ② 에러가 나면

**괜찮습니다.** 오늘 에러 한 번 안 만난 분이 오히려 드물어요.

빨간 글씨가 좌르르 뜨면 **처음 5줄만** 드래그해서 `Ctrl + C` 로 복사하고, 아래 틀에 넣어 보내주세요.

```
이 명령어를 실행했는데 에러가 났어:
npm run dev

에러 메시지야:
[빨간 글씨 처음 5줄 붙여넣기]

뭐가 문제인지, 뭘 확인해야 하는지 알려줘.
```

| 이럴 때 | 이렇게 해보세요 |
|---|---|
| `이 시스템에서 스크립트를 실행할 수 없으므로 ... npm.ps1` | 아래 [윈도우 노트북에서 자주 나오는 것](#윈도우-노트북에서-자주-나오는-것) 참고 |
| `localhost:3000` 주소가 안 보이고 빨간 글씨만 | 위 틀에 에러 붙여넣기 |
| 주소는 떴는데 화면이 하얗게 비어 있음 | `화면이 하얗게 비어 있어. 뭘 확인해야 해?` |
| 3000번 포트가 이미 쓰이고 있대요 | `3000번 포트가 이미 사용 중이래. 어떻게 해?` |
| 같은 에러가 세 번째 | `아까 알려준 대로 했는데 또 났어. 처음부터 다시 확인해줘.` |

**3분 넘게 막히시면 손 들어주세요.** 같이 화면 보면서 봐드릴게요.

혼자 오래 붙잡고 계시지 않는 게 우리 규칙이에요.

#### 윈도우 노트북에서 자주 나오는 것

`npm run dev` 를 쳤는데 이런 빨간 글씨가 나오는 분이 계실 거예요.

```
이 시스템에서 스크립트를 실행할 수 없으므로
C:\Program Files\nodejs\npm.ps1 파일을 로드할 수 없습니다.
```

**고장 난 게 아니에요.** 윈도우가 "이 명령을 실행해도 되나?" 하고 막아둔 상태입니다. 아래를 터미널에 붙여넣고 엔터, `Y` 를 누르시면 끝나요.

```
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

그다음 **터미널을 닫았다 다시 열고** `npm run dev` 를 한 번 더 쳐주세요.

:::note[이 명령이 뭘 바꾸나요]
"**내 계정에서는** 이런 명령을 실행해도 된다" 고 윈도우에 한 번 알려주는 겁니다.

- 컴퓨터 전체가 아니라 **내 계정에만** 적용돼요 (`-Scope CurrentUser`)
- 인터넷에서 받은 낯선 스크립트는 여전히 막아줍니다 (`RemoteSigned`)
- 한 번만 하면 되고, 다음 회차부터는 안 나와요
:::

### ③ 내 화면과 처음 만나기

좀 밋밋하죠. 흰 배경에 검은 글씨뿐이에요. 맞습니다, 오늘은 여기까지가 목표예요.

각자 진도가 다르니 먼저 되신 분은 먼저 3단계로 가셔도 좋아요. 기다리지 않으셔도 됩니다.

:::tip[다 만든 뒤에 이거 한 번만]
```
방금 만든 페이지가 내 목록이랑 하나도 안 빠지고 맞는지 확인해줘.
빠진 게 있으면 그것만 만들어줘.
```

## 3단계 · 돌아다니며 고치기 (30분)

### ① 한 바퀴 돌아보기

**이 순서로 클릭해보세요.** 오늘 제일 중요한 5분이에요.

1. 홈을 연다
2. 카드를 누른다 → 상세로 넘어가는지
3. 상세에서 다시 홈으로 온다
4. 다른 카드를 눌러본다

돌면서 이 4개를 확인해주세요.

- [ ] 내 목록에 있던 페이지가 **하나도 안 빠지고** 다 있다
- [ ] 카드를 누르면 **상세로 넘어간다**
- [ ] 상세에서 **홈으로 돌아올 수 있다**
- [ ] 화면 맨 위 제목이 내가 정한 이름이다 (`Page 1` 같은 게 아니라)

---

### ② 마음에 안 드는 곳 메모하기

돌아다니다 보면 어긋난 데가 눈에 들어올 거예요.

**바로 고치지 마시고, 먼저 메모부터** 해두세요. 세 개쯤 모이면 하나씩 고칩니다.

메모는 이 순서로 적으시면 됩니다.

> **어느 페이지 / 화면 어디 / 지금 어떤지 / 어떻게 됐으면 하는지**

이렇게요.

> 상세 페이지 / 맨 아래 / 홈으로 가는 링크가 없다 / "목록으로" 링크가 있으면 좋겠다

---

### ③ 메모를 그대로 프롬프트에 넣기

방금 적은 네 조각을 아래 틀에 그대로 옮기시면 됩니다.

```
[상세] 페이지에서 [맨 아래] 부분을 고치고 싶어.

지금: 홈으로 돌아가는 링크가 없어
이렇게 됐으면 해: "목록으로" 라는 링크가 있으면 좋겠어

이거 하나만 고쳐줘. 다른 파일은 건드리지 마.
```

**마지막 줄은 꼭 넣어주세요.** 이 한 줄이 없으면 AI가 옆 페이지까지 같이 고쳐놓거든요.

그리고 **한 번에 하나씩.** 세 개를 한꺼번에 시키면 하나만 제대로 되고 둘은 엉뚱하게 나옵니다.

---

### ④ 자주 나오는 세 가지

오늘 많이 나오는 것들이에요. 비슷한 게 보이면 그대로 쓰시면 됩니다.

**목록에 있던 페이지가 안 보일 때**

```
내 목록에는 [소개] 페이지가 있는데 화면에 없어.
[소개] 페이지만 만들어줘. 다른 페이지는 건드리지 마.
```

**"Lorem ipsum" 같은 영어가 들어 있을 때**

```
[홈] 페이지에서 [카드 안] 부분을 고치고 싶어.

지금: "Lorem ipsum" 같은 영어라서 뭐가 들어갈 자리인지 모르겠어
이렇게 됐으면 해: "여기에 카페 이름", "여기에 한 줄 평" 처럼 한국어로 적어줘

이거 하나만 고쳐줘. 다른 파일은 건드리지 마.
```

**브라우저 탭에 "Create Next App" 이라고 떠 있을 때**

```
브라우저 탭에 뜨는 이름을 [내 카페 기록] 으로 바꿔줘.
```

### ⑤ 고치고 나서 더 이상해졌다면

당황하지 않으셔도 돼요. 한 줄이면 돌아갑니다.

```
방금 바꾼 걸 되돌려줘. 그 전 상태로.
```

**AI가 시키지도 않은 걸 같이 고쳤을 때**

```
파일을 너무 많이 바꿨어.
앞으로는 고치기 전에 어느 파일을 왜 바꿀지 한 줄로 먼저 말해줘.
```

:::caution[이건 오늘 말고 메모만 해두세요]
돌아다니다 보면 **글씨가 작다 · 색이 밋밋하다 · 간격이 좁다 · 폰에서 깨진다** 같은 게 눈에 걸리실 거예요.

전부 5회차에 할 것들이에요. 오늘 고쳐두면 내일 기능 붙일 때 다시 깨지거든요.

메모장에 `5회차에 고칠 것` 이라고 적어두고 쌓아두세요. 5회차에 그 목록을 통째로 드리면 한 번에 끝나요.
:::

## 4단계 · GitHub에 중간 저장 (10분)

### ① 올리면 안 되는 것부터 확인 (2분)

프로젝트 안에는 **올리면 안 되는 파일**이 섞여 있어요. 그걸 걸러주는 게 `.gitignore` 라는 파일입니다. 이름 그대로 **"이건 무시해줘" 목록**이에요.

AI가 프로젝트를 만들 때 알아서 넣어뒀을 거예요. 그래도 **오늘 한 번만 눈으로 확인**하고 갑니다.

```
GitHub에 올리기 전에 .gitignore 를 확인해줘.

node_modules, .next, .env 로 시작하는 파일이 빠짐없이 들어 있는지 봐줘.
빠진 게 있으면 추가해주고, 지금 올라갈 파일 목록도 보여줘.
```

목록에 **`.env` 나 `.env.local` 이 보이면 올리지 마시고 손 들어주세요.**

:::caution[왜 오늘 굳이 확인하나요]
**내일 Supabase 열쇠(키)가 `.env` 파일에 들어옵니다.** 그게 GitHub에 올라가면 <mark>세상 사람 누구나 내 데이터베이스를 열 수 있어요.</mark>

한 번 올라간 건 지워도 기록에 남습니다. 그래서 오늘, 빈 상태일 때 미리 막아두는 거예요.

`node_modules` 는 다른 이유예요. 용량이 수백 MB라 올리면 오래 걸리는데, 필요하면 언제든 다시 받을 수 있는 파일이거든요.
:::

### ③ `CLAUDE.md` 새로 고치기 (3분)

2회차에 `CLAUDE.md` 를 만들 때는 폴더가 텅 비어 있었죠. 그래서 **계획**만 적혀 있어요.

지금은 실제 파일이 있으니, AI에게 **오늘 만든 걸 훑어보고 다시 적어달라고** 합니다. 이것만 치시면 돼요.

```
/init
```

:::caution[터미널 말고 **AI 채팅창**에 칩니다]
`/` 로 시작하는 건 전부 AI에게 하는 말이에요. 터미널에 치면 아무 일도 안 일어납니다.

| 이렇게 생긴 것 | 어디에 |
|---|---|
| `/init`, `/usage`, `/model` — **`/` 로 시작** | **AI 채팅창** |
| `npm run dev` 같은 영어 명령어 | **터미널** |
| `~~~ 해줘` 같은 한국어 부탁 | **AI 채팅창** |
:::

이러면 내일부터 AI가 내 프로젝트를 훨씬 잘 알아듣습니다.

**끝나면 `CLAUDE.md` 를 한 번 열어보세요.** `## 나에 대해` 와 `## 하지 말 것` 이 그대로 있으면 오늘 할 일 끝입니다.

혹시 그 부분이 사라졌으면 이 한 줄이면 돌아와요.

```
CLAUDE.md 에서 "나에 대해" 와 "하지 말 것" 부분이 사라졌어. 다시 넣어줘.
```
